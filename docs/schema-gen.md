Some of the RPC commands, events and Typescript Types are constructed via a JSON schema which is generated by Discord. To update the JSON schema, please do the following:

- From Discord, make sure the command or event is defined in `discord_common/js/packages/rpc-schema/definitions.tsx` with `embeddedAppSDK: true`, and that you have run `clyde gen rpc`
  - Only commands and events flagged with `embeddedAppSDK: true` are synced into this repo. Others in the schema are ignored.
  - Synced events are written between the `START-GENERATED-SECTION` sentinels in `src/schema/events.ts`. Events outside them are still hand-written.
- From the root of this github repo, run the following
  ```
  npm run sync -- --path path/to/monorepo/discord_common/js/packages/rpc-schema/generated/schema.json
  ```
  - By default the schema is read from the upstream of the monorepo's `main` branch, not your working tree. To sync from an unmerged branch, pass `--branch <branch-name>`.
- Commit your changes and update as needed
  - If a command stops being flagged, the script warns but does not delete its file in `src/commands/` or its entry in `src/mock.ts`. Remove those by hand.
